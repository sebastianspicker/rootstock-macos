# rootstock-graph

`rootstock-graph` is the Python part of Rootstock's Core workflow. It validates
collector artifacts, imports them into Neo4j, derives modeled relationships,
and produces queries, reports, and the local graph viewer.

This package is alpha software. Its schema, graph vocabulary, and command
behavior may change. Source setup, usage, limitations, and validation commands
are maintained in the [repository README](https://github.com/sebastianspicker/rootstock#readme).
